1. Foundations of Statistics

Before any formula, we need shared vocabulary. This module defines statistics itself, separates describing data from inferring from it, classifies the variables you'll be measuring, and covers the four ways researchers actually go out and collect a sample.

1.1 What is Statistics?

Statistics is the science of collecting, organizing, summarizing, analyzing, and drawing conclusions from data. A variable is any characteristic that can take different values; the actual recorded values are data. When a variable's value is left to chance, it's a random variable — an insurer can't predict which car crashes this year, but knows that on average 3% will.

Fig. 1.1 — A sample (orange) is a workable slice pulled from the full population (blue).

Descriptive vs. Inferential Statistics

📋 Descriptive Statistics

Collecting, organizing, summarizing and presenting data — e.g. reporting the average age from a census. No generalizing beyond the data in hand.

🔮 Inferential Statistics

Generalizing from a sample to a population: estimation, hypothesis testing, and prediction. This is where probability theory gets used.

1.2 Classifying Variables

Fig. 1.2 — Every variable in this course falls somewhere on this tree.

1.3 Levels of Measurement

Beyond qualitative/quantitative, every variable also sits on a "ladder" of how much information it carries:

Fig. 1.3 — Information content increases as you climb: nominal → ordinal → interval → ratio.

1.4 Sampling Methods

Since studying a full population is usually too costly, we sample it. Click each method below to see how it selects subjects.

Every dot is a member of the population; orange dots are the ones selected into the sample.
Key Points to Remember
  • Population = everyone being studied; sample = a selected subset used when a census is impractical.
  • Descriptive statistics summarizes what you have; inferential statistics generalizes to what you don't.
  • Quantitative variables split into discrete (countable) and continuous (measured, infinitely divisible).
  • Measurement levels, from weakest to strongest information: Nominal → Ordinal → Interval → Ratio. Only Ratio has a true zero.
  • Four sampling methods: Random (chance/number generator), Systematic (every k-th subject), Stratified (random pick within subgroups), Cluster (use whole intact subgroups).
  • Sampling error is simply the difference between a sample's result and the true population result.

2. Organizing Data: Frequency Distributions

Raw data — fifty temperature readings scattered on a page — tells you almost nothing at a glance. A grouped frequency distribution buckets it into classes so patterns (peaks, gaps, outliers) become visible. This is the very first "summarizing" step of descriptive statistics in action.

2.1 Building a Grouped Frequency Distribution

Procedure — 4 steps
Step 1 — Range: $R = H - L$   (highest − lowest value)
Step 2 — Class width: $\text{Width} = \dfrac{R}{\text{number of classes}}$, always round up
Step 3 — Class limits: start at a convenient number ≤ L, add the width repeatedly
Step 4 — Class boundaries: subtract 0.5 from every lower limit, add 0.5 to every upper limit
Boundaries close the gap between classes (e.g. 100–104 and 105–109 become 99.5–104.5 and 104.5–109.5) so continuous data has nowhere to "fall through the cracks."
Worked Example
Record high temperatures (°F) for all 50 US states. Construct a grouped frequency distribution using 7 classes. Highest $H=134$, Lowest $L=100$.
  1. Range: $R = 134 - 100 = 34$
  2. Class width: $34/7 = 4.86 \Rightarrow$ round up to $5$
  3. Class limits starting at 100, width 5: 100–104, 105–109, 110–114, … , 130–134
  4. Class boundaries: 99.5–104.5, 104.5–109.5, … , 129.5–134.5
  5. Tally the 50 data values into each class and count frequencies (table + chart below)

2.2 Cumulative Frequency Distribution

A cumulative frequency distribution shows how many data values fall at or below each upper boundary — just keep a running total. It answers questions like "how many states have a record high of 114°F or below?" (answer: 28).

Rule
cumulative freq. of class $i$ = cumulative freq. of class $(i-1)$ + freq. of class $i$
Key Points to Remember
  • Number of classes is usually chosen between 5 and 20 (often given to you in exam questions).
  • Always round the class width up — even if the division comes out exact, add an extra class to be safe.
  • Class boundaries (with the .5) are what make classes continuous with no gaps — used in every later formula (median, mode, quartiles).
  • Cumulative frequency of the last class always equals $N$, the total frequency.
  • Peaks in a distribution show where data concentrates; extreme values far from the rest are called outliers.

3. Measures of Central Tendency

A measure of central tendency compresses an entire data set into one representative number — useful for comparison, ranking, and reporting. This module covers all five classical measures: mean, median, mode, geometric mean, and harmonic mean.

3.1 Arithmetic Mean

The mean is the total of all observations divided by how many there are. For grouped data with a wide range, the short-cut (step-deviation) method avoids large multiplications.

Direct method
$\bar{X} = \dfrac{\sum X_i}{N}$   or, for frequency data,   $\bar{X}=\dfrac{\sum f_i X_i}{\sum f_i}$
Short-cut / step-deviation method
$\bar{X} = A + \dfrac{\sum f_i d_i}{N}\times h,\quad d_i = \dfrac{x_i - A}{h}$
$A$ = assumed mean (a convenient mid-value)  ·  $h$ = class width
Worked Example — Short-cut Method
Marks of 80 students: classes 0–20, 20–40, … ,120–140 with frequencies 4, 26, 22, 10, 9, 6, 3. Take $A=70$, $h=20$.
  1. Compute $d_i = (x_i - 70)/20$ for each class midpoint, giving −3,−2,−1,0,+1,+2,+3
  2. Multiply by frequency: $f_id_i$ = −12,−52,−22, 0, +9, +12, +9
  3. Sum: $\sum f_i d_i = -56$
  4. Apply formula: $\bar{X} = 70 + \dfrac{-56}{80}\times 20 = $ $56$

3.2 Median

The middle value once data is sorted — unaffected by extreme outliers, unlike the mean.

Ungrouped data
$N$ odd: median = $\left(\dfrac{N+1}{2}\right)^{th}$ value
$N$ even: average of $\left(\dfrac{N}{2}\right)^{th}$ & $\left(\dfrac{N}{2}+1\right)^{th}$ values
Grouped data
$\text{Median} = L + \dfrac{\frac{N}{2} - \text{p.c.f}}{f}\times h$
$L$ = lower boundary of median class · p.c.f = cumulative freq. before median class · $f$ = freq. of median class

3.3 Quartiles, Deciles & Percentiles

These generalize the median: quartiles cut data into 4 equal parts, deciles into 10, percentiles into 100. $Q_2$ = median.

General position formula (grouped data)
$Q_i = L + \dfrac{\frac{iN}{4}-\text{p.c.f}}{f}\times h \;\;(i=1,2,3)\qquad D_i = L+\dfrac{\frac{iN}{10}-\text{p.c.f}}{f}\times h\;\;(i=1..9)\qquad P_i = L+\dfrac{\frac{iN}{100}-\text{p.c.f}}{f}\times h\;\;(i=1..99)$
Fig. 3.1 — Quartiles slice sorted data into four equal-frequency bands.

3.4 Mode

The value occurring most often — the only central-tendency measure that works for purely qualitative data too.

Grouped data
$\text{Mode} = L + \dfrac{\Delta_1}{\Delta_1+\Delta_2}\times h$
$L$ = lower boundary of modal class (highest frequency) · $\Delta_1$ = (modal freq. − pre-modal freq.) · $\Delta_2$ = (modal freq. − post-modal freq.)

3.5 Geometric & Harmonic Mean

Geometric Mean
$GM = \text{Antilog}\left(\dfrac{\sum \log X_i}{N}\right)$
best for growth rates / ratios (interest rates, index numbers)
Harmonic Mean
$HM = \dfrac{N}{\sum \left(\frac{1}{X_i}\right)}$
best for rates / speeds (km per hour, price per unit)

3.6 The Empirical Relationship

Very exam-favorite formula
$\text{Mode} = 3\,\text{Median} - 2\,\text{Mean}$
Lets you find any one of the three if you already know the other two — for a moderately skewed distribution.
Worked Example — All Three, Linked
Weights of 150 students: classes 30–40…80–90 with frequencies 18, 37, 45, 27, 15, 8. (Median class 50–60, Modal class 50–60.)
  1. Median $= 50 + \dfrac{75-55}{45}\times 10 = $ 54.44
  2. Mode $= 50 + \dfrac{8}{8+18}\times 10 = $ 53.08
  3. Using the empirical relation: $\text{Mean} = \dfrac{3(54.44)-53.08}{2} = $ 55.12
Fig. 3.2 — Where mean, median, and mode sit relative to each other tells you the shape (preview of Module 4).
Key Points to Remember
  • Mean uses every value, so it's sensitive to outliers; median ignores extremes and is more "robust."
  • For grouped data, always locate the correct class first using cumulative frequency — median/quartile class is where $\frac{iN}{4}$ (or $\frac{N}{2}$) falls, modal class is simply the one with highest frequency.
  • The empirical relation $\text{Mode}=3\text{Median}-2\text{Mean}$ only holds for moderately skewed distributions — memorize it, exams love it.
  • Geometric Mean suits growth/ratio data; Harmonic Mean suits rate data (speed, price per unit).

4. Skewness, Moments & Kurtosis

Central tendency tells you where data sits; dispersion tells you how spread out it is. Neither tells you the shape. Skewness measures asymmetry (which side has the longer tail), and kurtosis measures peakedness. Moments are the unifying mathematical machine behind both.

4.1 What is Skewness?

Skewness is lack of symmetry. Where measures of variation tell you the amount of spread, measures of skewness tell you its direction.

Fig. 4.1 — In (b) mean > mode with median between; in (c) mode > mean with median between.

4.2 Measures of Skewness

Karl Pearson's Coefficient
$SK_P = \dfrac{\text{Mean}-\text{Mode}}{\sigma}$
Bowley's Coefficient
$SK_B = \dfrac{Q_3+Q_1-2Q_2}{Q_3-Q_1}$
Kelly's Coefficient
$SK_K = \dfrac{P_{90}-2P_{50}+P_{10}}{P_{90}-P_{10}} = \dfrac{D_9-2D_5+D_1}{D_9-D_1}$
Rule for all three: value $>0 \Rightarrow$ positively skewed  ·  $=0 \Rightarrow$ symmetric  ·  $<0 \Rightarrow$ negatively skewed
Worked Example — Karl Pearson's Coefficient
Profits of 1000 companies. Computed: Mean $= 177.86$, Mode $= 190.56$, $\sigma = 25.2$.
  1. $SK_P = \dfrac{177.86-190.56}{25.2} = $ $-0.504$
  2. Interpretation: mode exceeds mean by about 50.4% of a standard deviation → moderately negatively skewed distribution.

4.3 Moments

Moments are a family of descriptive measures that, taken together, uniquely characterize a distribution — mean, variance, skewness and kurtosis are all just specific moments.

Raw moments (about assumed mean A)
$\mu'_r = \dfrac{\sum f_i(x_i-A)^r}{N} = \dfrac{\sum f_i d_i^{\,r}}{N}\times h^r$
Central moments (about mean X̄)
$\mu_r = \dfrac{\sum f_i(x_i-\bar{X})^r}{N}$
Conversion — raw → central (memorize these four)
$\mu_1 = 0$
$\mu_2 = \mu'_2 - (\mu'_1)^2$   ← this is the variance $\sigma^2$
$\mu_3 = \mu'_3 - 3\mu'_1\mu'_2 + 2(\mu'_1)^3$   ← relates to skewness
$\mu_4 = \mu'_4 - 4\mu'_1\mu'_3 + 6(\mu'_1)^2\mu'_2 - 3(\mu'_1)^4$   ← relates to kurtosis
Worked Example — First Four Moments
Profits of 100 companies, classes 10–20…50–60, freq. 18,20,30,22,10. Using $A=35$, $h=10$: $\sum f_id_i=-14,\;\sum f_id_i^2=154,\;\sum f_id_i^3=-62,\;\sum f_id_i^4=490$.
  1. Raw moments: $\mu'_1=-1.4,\ \mu'_2=154,\ \mu'_3=-620,\ \mu'_4=49000$
  2. Central moments: $\mu_1=0$
  3. $\mu_2 = 154-(-1.4)^2 = $ 152.04
  4. $\mu_3 = -620-3(154)(-1.4)+2(-1.4)^3 = $ 21.312
  5. $\mu_4 = 49000-4(-620)(-1.4)+6(154)(-1.4)^2-3(-1.4)^4 = $ 47327.51

4.4 Kurtosis

Kurtosis measures peakedness relative to the normal curve.

Fig. 4.2 — All three curves share the same mean and area, but differ in how "pointy" the peak is.

4.5 Skewness & Kurtosis via Moments

Skewness coefficients
$\beta_1 = \dfrac{\mu_3^2}{\mu_2^3} \qquad \gamma_1 = \sqrt{\beta_1} = \dfrac{\mu_3}{\mu_2^{3/2}}$
$\beta_1$ is always positive (can't show direction) — use $\gamma_1$ instead: $\gamma_1=0$ symmetric, $\gamma_1>0$ positive skew, $\gamma_1<0$ negative skew
Kurtosis coefficients
$\beta_2 = \dfrac{\mu_4}{\mu_2^2} \qquad \gamma_2 = \beta_2 - 3$
$\beta_2>3\,(\gamma_2>0)$ leptokurtic  ·  $\beta_2=3\,(\gamma_2=0)$ mesokurtic  ·  $\beta_2<3\,(\gamma_2<0)$ platykurtic
Worked Example — Putting It All Together
Employee earnings, 7 classes (60 workers). Computed central moments: $\mu_2=926.56,\ \mu_3=4774.832,\ \mu_4=21{,}951{,}073$.
  1. $\gamma_1 = \dfrac{4774.832}{926.56^{1.5}} = $ 0.1693 → slightly right-skewed (not perfectly symmetric)
  2. $\beta_2 = \dfrac{21951073}{926.56^2} = 2.56 \Rightarrow \gamma_2 = \beta_2-3 = $ −0.44 → distribution is platykurtic (flatter than normal)
Key Points to Remember
  • Skewness = direction of asymmetry; Kurtosis = peakedness. They answer different questions about shape.
  • Karl Pearson's coefficient needs the mode (can be unreliable if mode is ill-defined) — Bowley's and Kelly's use only quartiles/percentiles, so they're more robust for skewed or open-ended data.
  • The 1st central moment is always 0 by definition (deviations from the mean cancel out); the 2nd central moment is the variance.
  • $\beta$ values are always positive; use the signed $\gamma$ values to read direction.
  • Mesokurtic = normal curve = the benchmark ($\beta_2=3$ exactly).
🎓 Possible Exam Questions
1If Mean = 36.96, Mode = 37.21, σ = 6.736, find Karl Pearson's coefficient of skewness and interpret it.tap to reveal
$SK_P = \frac{36.96-37.21}{6.736}=-0.037$ — very close to 0, distribution is only slightly negatively skewed (nearly symmetric).
2Why is $\beta_1$ (not $\gamma_1$) unable to tell you the direction of skewness?tap to reveal
Because $\beta_1=\mu_3^2/\mu_2^3$ squares $\mu_3$, destroying its sign — a square is always non-negative regardless of whether the original skew was left or right. $\gamma_1$ keeps $\mu_3$ unsquared (via square root with sign), preserving direction.
3A distribution has $\mu_2=64$ and $\mu_4=15{,}000$. Is it lepto-, meso-, or platykurtic?tap to reveal
$\beta_2 = 15000/64^2 = 3.66 > 3 \Rightarrow \gamma_2=0.66>0 \Rightarrow$ leptokurtic (more peaked than normal).

5. Foundations of Probability

We now flip from describing data we already have to reasoning about outcomes we haven't seen yet. This module builds the toolkit: random experiments, set operations, counting (permutations & combinations), and the classical probability formula.

5.1 Random Experiments

A random experiment is one where (a) all possible outcomes are known in advance, (b) the actual outcome of any one trial is unknown beforehand, and (c) it can be repeated under identical conditions. The set of all possible outcomes is the sample space $S$.

Toss a coin → S={H,T} Roll a die → S={1,2,3,4,5,6} Draw a card → S = 52 cards Two children → S={BB,BG,GB,GG}

Two events are equally likely if they share the same chance of occurring — e.g. getting Heads vs. Tails on a fair coin.

5.2 Set Theory & De Morgan's Laws

Events are sets, so unions ($A\cup B$ = A or B), intersections ($A\cap B$ = A and B), and complements ($A^c$ = not A) all apply. Click a button to highlight each region below.

Fig. 5.1 — De Morgan: $(A\cup B)^c = A^c \cap B^c$. Compare the last two buttons — they occupy the same region.

5.3 Permutations vs. Combinations

Permutation — order matters
${}_nP_r = \dfrac{n!}{(n-r)!}$
Arranging 3 books ABC on a shelf → ${}_3P_3=6$ orders: ABC, ACB, BAC, BCA, CAB, CBA
Combination — order doesn't matter
${}_nC_r = \dfrac{n!}{r!(n-r)!}$
Choosing 2 of 3 books to take on a trip → ${}_3C_2=3$ selections: AB, AC, BC
Worked Example — Combinations with a Constraint
20 people: 8 men, 12 women. Form a 5-person committee with exactly 3 men and 2 women.
  1. Choose men: ${}_8C_3 = $ 56 ways
  2. Choose women: ${}_{12}C_2 = $ 66 ways
  3. Choices are independent, so multiply: $56\times 66 = $ 3696 committees

5.4 Classical Probability & the Multiplication Rule

Classical Approach — requires equally likely outcomes
$P(A) = \dfrac{n(A)}{n(S)}$
Other approaches exist too: relative frequency (based on repeated trials) and subjective (based on judgement) — but classical is what we compute with in this course.
Independent events
$P(A\cap B) = P(A)\times P(B)$
Dependent events
$P(A\cap B) = P(A)\times P(B|A)$
Fig. 5.2 — A probability tree for dependent events: multiply along each branch.
Key Points to Remember
  • A sample space $S$ must list every possible outcome — get this wrong and every downstream probability is wrong.
  • Permutation = order matters (arrangements); Combination = order doesn't matter (selections). Combinations are always $\le$ permutations for the same $n,r$.
  • Classical probability $P(A)=n(A)/n(S)$ only works when outcomes are equally likely — check this assumption before using it.
  • Independent events: knowing one tells you nothing about the other, so probabilities simply multiply. Dependent events: you must condition — $P(B|A)$ changes after $A$ happens (as in "without replacement" problems).
🎓 Possible Exam Questions

Order doesn't matter → combination: ${}_5C_3 = \dfrac{5!}{3!2!}=$ 10.

$P(\text{even})=3/6=1/2$; $P(>4)=2/6=1/3$. Since $1/2 \ne 1/3$, not equally likely.

6. Odds & Joint Probability

"Odds" are how bookmakers and everyday speech express chance — and they convert cleanly to probability. Then we build up to joint probability, which handles two events happening together, and the joint probability table that organizes it all.

6.1 Odds

Odds compare success against failure directly, rather than success against the whole sample space.

Odds in favor of A
$O_A = \dfrac{P(A)}{1-P(A)} = \dfrac{n(A)}{n(A^c)}$
Odds against A
$O_{A^c} = \dfrac{n(A^c)}{n(A)}$   (reciprocal of odds in favor)
Converting odds → probability
If odds in favor of A are $a:b$, then $P(A)=\dfrac{a}{a+b}$ and $P(A^c)=\dfrac{b}{a+b}$
Worked Example
The probability of an athlete winning a race is 0.2. Find the odds against winning.
  1. $P(\text{win})=0.2 \Rightarrow P(\text{lose})=0.8$
  2. Odds against $= \dfrac{0.8}{0.2} = $ 4, i.e. 4:1
  3. Interpretation: for every 1 chance of winning, there are 4 chances of losing.

6.2 Joint Probability

Joint probability $P(A\cap B)$ is the chance that two (or more) events happen at the same time.

General addition rule (recap — needed constantly here)
$P(A\cup B) = P(A)+P(B)-P(A\cap B)$

6.3 The Joint Probability Table

A 2×2 table is the cleanest way to organize two binary events at once — every cell is a joint probability, and row/column totals are marginal probabilities.

Worked Example — Two Machines
Machine A makes 40% of items (5% defective); Machine B makes 60% (10% defective). Build the joint table and find: (i) P(item is defective), (ii) P(from A | defective).
Y = DefectiveY′ = Not DefectiveTotal

Total0.080.921.00
  1. P(defective) = sum down the "Defective" column = $0.02+0.06=$ 0.08
  2. P(Machine A | defective) $=\dfrac{P(A\cap Y)}{P(Y)}=\dfrac{0.02}{0.08}=$ 0.25 (25%)

Marginal distribution is simply the row totals (distribution of X alone) or column totals (distribution of Y alone) — "marginal" because they sit in the table's margins.

Key Points to Remember
  • Odds in favor and odds against are always reciprocals of each other.
  • To go from odds $a:b$ to probability, divide each side by the total: $P=\frac{a}{a+b}$.
  • In a joint probability table, every cell is a joint probability $P(X\cap Y)$; every total is a marginal probability $P(X)$ or $P(Y)$; and all cells sum to 1.
  • Reading "P(from A | defective)" out of the table is really just conditional probability wearing a table costume — a preview of Module 7.

7. Conditional Probability & Bayes' Theorem

This is the capstone of the probability half of the course. Conditional probability asks "given that I already know B happened, how likely is A?" Bayes' theorem then flips that around — letting you go from $P(\text{evidence}|\text{cause})$ to the far more useful $P(\text{cause}|\text{evidence})$.

7.1 Conditional Probability

Definition
$P(A|B) = \dfrac{P(A\cap B)}{P(B)}, \quad P(B)\neq 0$
Read as "probability of A given B." In general $P(A|B)\neq P(B|A)$ — mixing these up is the #1 exam mistake.
Fig. 7.1 — Conditioning on B shrinks the universe to just B; $P(A|B)$ is what fraction of that new, smaller world is also in A.

7.2 The Multiplication Law (General Form)

For k events
$P(A_1\cap A_2\cap\cdots\cap A_k) = P(A_1)\,P(A_2|A_1)\,P(A_3|A_1\cap A_2)\cdots P(A_k|A_1\cap\cdots\cap A_{k-1})$

7.3 Bayes' Theorem

The formula that "flips" a conditional probability
$P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B|A)P(A) + P(B|A^c)P(A^c)}$
Numerator = the one branch you care about. Denominator = every way B could have happened (total probability). For $k$ competing causes $A_1,\dots,A_k$:   $P(A_i|D)=\dfrac{P(A_i)P(D|A_i)}{\sum_j P(A_j)P(D|A_j)}$
Worked Example — The Classic Diagnostic Test Paradox
A blood test detects a disease 90% of the time when present, but gives a false positive 5% of the time when absent. Only 1% of the population actually has the disease. If a random person tests positive, what's the probability they actually have the disease?
Fig. 7.2 — Only the two "Positive" branches (highlighted) matter for our answer.
  1. $P(D)=0.01,\;P(P|D)=0.90,\;P(D^c)=0.99,\;P(P|D^c)=0.05$
  2. $P(P) = (0.01)(0.90)+(0.99)(0.05) = 0.009+0.0495 = $ 0.0585
  3. $P(D|P) = \dfrac{0.009}{0.0585} \approx $ 0.154 (about 15%)
💡 The Base-Rate Fallacy

A "90% accurate" test that comes back positive only means you're 15% likely to actually be sick! Why? Because the disease is rare (1%), so even a small false-positive rate (5%) applied to the huge healthy majority produces more false positives (0.0495) than true positives (0.009). This is called the base-rate fallacy — ignoring how common something is in the first place — and it's one of the most tested real-world applications of Bayes' theorem, in medicine, law, and spam filtering alike.

Key Points to Remember
  • $P(A|B)\ne P(B|A)$ in general — always define events in words first to avoid flipping them.
  • Bayes' theorem's denominator is just the law of total probability: every path that could lead to the observed evidence, added up.
  • A low base rate (rare disease/rare event) can make even an accurate-sounding test surprisingly unreliable in practice — always check the prior, not just the test's accuracy.
  • For more than 2 competing causes, extend the denominator to sum over all of them: $\sum_j P(A_j)P(D|A_j)$.
