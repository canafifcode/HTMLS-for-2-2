Non-Regular Languages
& the Pumping Lemma

Finite automata are powerful — but finite memory has fundamental mathematical limits. This is a complete, corner-to-corner study companion to Lecture 6, built around one recurring idea: assume → p → s → trap y → pump.

Part I

A suspicious language

§1Why Finite Memory Fails

Consider the language of perfectly balanced binary strings:

B = { 0n1n | n ≥ 0 }

To accept 00001111, a machine must somehow "remember" that it saw exactly four 0s so it can later verify exactly four 1s.

The problem: a DFA only has a fixed number of states — say p states. What happens when we feed it p + 1 zeros? There simply aren't enough states left to keep counting. Something has to give — and that "something" is the seed of the whole lecture.

The engine of the proof

§2The Pigeonhole Principle in Directed Graphs

A DFA is simply a directed graph. Reading a string is just tracing a walk through that graph.

Pigeonhole Principle

If you put m + 1 pigeons into m holes, at least one hole contains two pigeons.

If a DFA has p states and it reads a string of length p or greater, it visits at least p + 1 states (counting the start state). Therefore, it must visit at least one state twice.

The pigeonhole principle, restated for automata: reading p+1 symbols visits p+1 states, but only p exist.

Graph theory

§3Revisiting a State Creates a Cycle

In graph theory, a walk that intersects itself contains a cycle. Let the string be s = xyz:

  • x — the path from the start state to the first time we hit the repeated state.
  • y — the cycle itself (leaving the repeated state and returning to it).
  • z — the path from the repeated state onward to the accept state.

The repeated state splits any long accepted string into x (get there), y (the loop), z (finish up).

The key insight

§4The "Pump"

Because y is a cycle, the DFA doesn't actually know how many times it loops. If the DFA accepts xyz, it has no choice but to also accept:

  • xz — looping 0 times, skipping y entirely
  • xyyz — looping 2 times
  • xyyyz — looping 3 times
  • … and so on, for every i ≥ 0
Core intuition. Any sufficiently long string accepted by a regular language must contain a cycle that can be "pumped" — repeated any number of times — without ever leaving the language.
Sipser's theorem

§5The Pumping Lemma for Regular Languages

Theorem

If A is a regular language, then there exists a number p (the pumping length) such that every string s ∈ A with |s| ≥ p can be divided into three pieces, s = xyz, satisfying all three conditions:

  1. for each i ≥ 0,   xyiz ∈ A
  2. |y| > 0
  3. |xy| ≤ p

Why |y| > 0? The cycle must consume at least one character — otherwise there is nothing to pump.

Why |xy| ≤ p? By the pigeonhole principle, the first duplicate state must occur within the first p steps — so the repeated state is guaranteed to fall somewhere inside the first p characters of s.

Turning the theorem into a weapon

§6The Logic of Contradiction

The Pumping Lemma is an implication:

If A is regular  ⟹  A has the pumping property.

By modus tollens, if A does not have the pumping property, then A is not regular. That's the entire strategy of this lecture in one sentence.

The lemma hides heavily nested quantifiers:

∃p, ∀s, ∃x,y,z, ∀i …

To prove a language is not regular, we negate this statement — every ∃ flips to ∀ and every ∀ flips to ∃:

∀p, ∃s, ∀x,y,z, ∃i …
A game against a demon

§7The Adversary Game

Think of the proof as a turn-based game against a Setup Demon who claims A is regular. You win if you force a contradiction.

Turn 1
Demon
Chooses the pumping length p. You don't know p — treat it as a variable, never a number.
Turn 2
You
Choose a target string s ∈ A such that |s| ≥ p. This is your one creative move — express s in terms of p.
Turn 3
Demon
Divides your string into s = xyz however they like — as long as |y| > 0 and |xy| ≤ p.
Turn 4
You
Choose a pump count i ≥ 0 such that xyiz ∉ A.
Rule of rigor. You cannot choose the split (x, y, z) — the demon does. You must prove your i works for every valid split the demon could possibly make.
The recipe you will use again and again

§8The Rigorous 5-Step Proof Template

Every valid Pumping Lemma proof in this document follows exactly this structure — the same staircase shape reappears in every worked example below.

  1. 1
    Assume for contradiction

    Assume that language L is regular.

  2. 2
    Let p be the pumping length

    The Pumping Lemma guarantees such a p exists — you don't get to pick its value.

  3. 3
    Choose a specific string s ∈ L, |s| ≥ p

    This is your creative step — express s in terms of p.

  4. 4
    Split and trap y

    By the lemma, s = xyz with |y| > 0 and |xy| ≤ p. Analyze exactly what y must look like given this constraint.

  5. 5
    Pump and contradict

    Choose an i ≥ 0. Show mathematically that xyiz ∉ L, contradicting the lemma. Conclude L is not regular.

Part II

§9Five Core Worked Proofs

Same five moves, five different languages. Watch how the "trap" on y and the choice of i change each time — everything else is boilerplate.

Example 1

Matching Two Blocks

L1 = { 0n1n | n ≥ 0 }
  1. 1

    Assume for contradiction that L1 is regular.

  2. 2

    Let p be its pumping length.

  3. 3

    Choose s = 0p1p. Clearly s ∈ L1 and |s| = 2p ≥ p.

  4. 4

    For every valid split with |xy| ≤ p and |y| > 0, both x and y lie inside the first block of 0s. Hence y = 0k for some 1 ≤ k ≤ p.

  5. 5

    Choose i = 0. Then xy0z = xz = 0p−k1p. This has p−k zeros but still p ones. Since k > 0, p−k ≠ p, so xz ∉ L1 — contradiction. L1 is not regular. ∎

Intuition. The machine is forced to repeat or remove some early 0s without touching the later 1s, breaking the exact count.
Example 2

Palindromes

L2 = { w ∈ {a,b}* | w = wR }
  1. 1

    Assume for contradiction that L2 is regular.

  2. 2

    Let p be its pumping length.

  3. 3

    Choose s = apbap. This is a palindrome, and |s| = 2p+1 ≥ p.

  4. 4

    |xy| ≤ p forces y entirely inside the first block of as. Thus y = ak for some 1 ≤ k ≤ p.

  5. 5

    Choose i = 0. Then xy0z = ap−kbap. The left of the central b now has p−k copies of a, the right still has p. Since k > 0, the halves differ — the string is no longer a palindrome. Contradiction. L2 is not regular. ∎

Intuition. Pumping only edits the left half, so the mirror image no longer matches.
Example 3

Synchronizing Three Blocks

L3 = { anbncn | n ≥ 0 }
  1. 1

    Assume for contradiction that L3 is regular.

  2. 2

    Let p be its pumping length.

  3. 3

    Choose s = apbpcp. Clearly s ∈ L3 and |s| = 3p ≥ p.

  4. 4

    |xy| ≤ p places y completely inside the initial block of as. Therefore y = ak for some 1 ≤ k ≤ p.

  5. 5

    Choose i = 2. Then xy2z = ap+kbpcp. The counts are now p+k, p, p — not all equal since k > 0. Contradiction. L3 is not regular. ∎

Intuition. A finite automaton cannot keep three arbitrarily large blocks perfectly synchronized.
Example 4

Copying Across a Separator

Σ = {0,1,#}    L4 = { w#w | w ∈ {0,1}* }
  1. 1

    Assume for contradiction that L4 is regular.

  2. 2

    Let p be its pumping length.

  3. 3

    Choose s = 0p1#0p1. The word 0p1 appears on both sides of #, so s ∈ L4, and |s| = 2p+3 ≥ p.

  4. 4

    |xy| ≤ p forces y into the first block of 0s. Hence y = 0k for some 1 ≤ k ≤ p.

  5. 5

    Choose i = 0. Then xy0z = 0p−k1#0p1. The word left of # is now shorter than the word on the right — they differ since k > 0. Contradiction. L4 is not regular. ∎

Intuition. Pumping edits the first copy but leaves the second copy completely untouched.
Example 5

Unary Strings of Square Length

L5 = { an2 | n ≥ 0 }
  1. 1

    Assume for contradiction that L5 is regular.

  2. 2

    Let p ≥ 1 be its pumping length.

  3. 3

    Choose s = ap2. Since p2 is a perfect square, s ∈ L5, and |s| = p2 ≥ p.

  4. 4

    Every valid split has y = ak for some 1 ≤ k ≤ p.

  5. 5

    Choose i = 2. Then |xy2z| = p2+k. Since 1 ≤ k ≤ p:   p2 < p2+k ≤ p2+p < (p+1)2. The new length lies strictly between two consecutive perfect squares, so it isn't one. Contradiction. L5 is not regular. ∎

p² + k is trapped strictly between two consecutive perfect squares — it cannot itself be a square.

Intuition. Even over a one-symbol alphabet, a DFA cannot track the widening gaps between perfect squares.

Self-grading

§11Checklist for Student Proofs

When grading your own proof, ask:

  • Did I say "let p be the pumping length"? (Never invent a value like p = 5.)
  • Did I choose a string s using p?
  • Did I verify both s ∈ L and |s| ≥ p?
  • Did I use |xy| ≤ p to prove exactly where y must occur?
  • Did I handle every valid split rather than choosing y myself?
  • Did I select an i and clearly prove that xyiz ∉ L?
Part III

§12When Pumping Becomes Tedious

Sometimes a direct pumping argument is awkward — pumping may accidentally preserve the property you're trying to break. Closure properties can reveal the contradiction faster.

Closure 1

Unequal Block Lengths

L≠ = { 0m1n | m,n ≥ 0, m ≠ n }
  • Assume L≠ is regular.
  • The language R = 0*1* is regular.
  • Regular languages are closed under set difference.
  • Therefore R \ L≠ must be regular.
  • But R \ L≠ = { 0n1n | n ≥ 0 } — which Example 1 already proved is not regular.
Contradiction. Therefore L≠ is not regular. ∎ The trick: subtracting away everything with "unequal" leaves exactly the equal-count language we already broke.
Closure 2

Strict Inequality

L< = { 0m1n | m < n }
  • Assume L< is regular.
  • Regular languages are closed under reversal. Reversing L< and swapping 0 ↔ 1 produces the regular language L> = { 0m1n | m > n }.
  • Hence L< ∪ L> = { 0m1n | m ≠ n } would be regular (closure under union).
  • Since 0*1* is regular, its difference with this union would also be regular:   0*1* \ (L< ∪ L>) = { 0n1n | n ≥ 0 }.
Contradiction. This is impossible — so L< is not regular. ∎ Notice how reversal, union, and difference stack together to reduce the problem back to 0n1n once more.

Your turn

§14Problems to Try at Home

Use the five-step template on each. A light strategic nudge is given — the proof is yours to complete.

  1. L₁
    { 0m1n | m ≠ n }
    Try the closure-under-difference route from Closure Proof 1, or pump directly with a carefully chosen s.
  2. L₂
    { 0m1n | gcd(m,n) = 1 }
    Pick s so that m and n start coprime, then ask what pumping does to the gcd.
  3. L₃
    { 0m1n | m divides n, m,n ≥ 1 }
    Divisibility is fragile — pumping the smaller block by even one symbol usually breaks it.
  4. L₄
    { (ab)ncn | n ≥ 0 }
    Structurally close to Example 1 — the (ab) block just replaces the 0 block.
  5. L₅
    { an! | n ≥ 1 }
    Factorial growth leaves enormous gaps — similar spirit to the square-length example.
  6. L₆
    { aFn | n ≥ 0, Fn the nth Fibonacci number }
    This is solved in full as an Advanced Case Study below — try it first, then compare.
  7. L₇
    balanced parentheses over {(, )}
    Nesting depth needs unbounded memory — pump inside the parentheses and count the imbalance.
Part IV

§15Advanced Case Studies

Five deeper examples, each paired with the specific misconceptions students fall into. Click "Common Errors" on each card to expand.

Case A

Unequal Numbers of 0s and 1s

L≠ = { w ∈ {0,1}* | #0(w) ≠ #1(w) }, where #σ(w) counts occurrences of σ in w.

Proved using closure properties rather than direct pumping:

  1. Assume for contradiction that L≠ is regular.
  2. Regular languages are closed under complement, so E = {0,1}* \ L≠ = { w | #0(w) = #1(w) } must be regular.
  3. R = 0*1* is regular.
  4. Regular languages are closed under intersection, so E ∩ R must be regular.
  5. But E ∩ R = { w ∈ 0*1* | #0(w) = #1(w) } = { 0n1n | n ≥ 0 }, which is not regular.
Contradiction. Therefore L≠ is not regular. ∎ Intersecting with 0*1* forces all 0s before all 1s, exposing the familiar 0n1n language hiding inside.
Common errors & misconceptions
  • The original language contains strings in any order — 0101, 1100, 1010 — it is not restricted to the form 0m1n.
  • The complement of L≠ is { w | #0(w)=#1(w) }, not immediately { 0n1n }.
  • We only obtain { 0n1n } after intersecting with 0*1*.
  • A complement must always be taken relative to a fixed universe — here that universe is {0,1}*.
Case B

Unary Strings of Prime Length

Lprime = { at | t is prime }
  1. 1

    Assume for contradiction that Lprime is regular.

  2. 2

    Let p be the pumping length.

  3. 3

    There are infinitely many primes, so choose a prime q > p, and let s = aq. Then s ∈ Lprime and |s| = q ≥ p.

  4. 4

    For every valid decomposition, y = ak for some 1 ≤ k ≤ p.

  5. 5

    Choose i = q+1. Replacing one copy of y with q+1 copies adds qk symbols, so |xyq+1z| = q + qk = q(k+1). Since q ≥ 2 and k+1 ≥ 2, this length is a product of two integers greater than 1 — composite. Contradiction. Lprime is not regular. ∎

Common errors & misconceptions
  • The pumping length p is an arbitrary positive integer — it is not necessarily prime.
  • We do not choose s = ap, because p may be composite. Instead, after receiving p, we choose a separate prime q > p.
  • We do not choose y — the adversary does. We only conclude y = ak, 1 ≤ k ≤ p.
  • Pumping with i = q+1 does not make the length (q+1)k. The correct length is q + (i−1)k = q + qk = q(k+1).
  • The pump count i may depend on p and the chosen string — it does not have to be a fixed constant.
Case C

Unary Strings of Composite Length

Lcomp = { at | t is composite }

Recall that 0 and 1 are neither prime nor composite, so a* = Lprime ∪ Lcomp ∪ {ε, a}.

  1. Assume for contradiction that Lcomp is regular.
  2. The finite language {ε, a} is regular, so Lcomp ∪ {ε, a} would be regular.
  3. Regular languages are closed under difference, so a* \ (Lcomp ∪ {ε, a}) would be regular.
  4. But a* \ (Lcomp ∪ {ε, a}) = Lprime, which Case B already proved is not regular.
Contradiction. Therefore Lcomp is not regular. ∎ Primes and composites cover all positive unary lengths except length 1 — and length 0 (ε) must also be carved out separately.
Common errors & misconceptions
  • The complement of the composite-length language is not exactly the prime-length language.
  • ε = a0 and a = a1 have lengths 0 and 1, which are neither prime nor composite.
  • Therefore a* \ Lcomp = Lprime ∪ {ε, a}.
  • To isolate the prime-length language, we must remove both Lcomp and {ε, a}.
  • The proof leans on the earlier result that Lprime is not regular — it does not stand alone.
Case D

Unary Strings of Fibonacci Length

F0=0, F1=1, Fn+1=Fn+Fn−1    LFib = { aFn | n ≥ 0 }
  1. 1

    Assume for contradiction that LFib is regular.

  2. 2

    Let p be its pumping length.

  3. 3

    Fibonacci numbers grow without bound, so choose m ≥ 3 large enough that Fm−1 > p. Let s = aFm. Since Fm > Fm−1 > p, we have s ∈ LFib and |s| ≥ p.

  4. 4

    For every valid decomposition, y = ak for some 1 ≤ k ≤ p.

  5. 5

    Choose i = 2. Then |xy2z| = Fm + k. Since k ≥ 1, Fm < Fm+k. Since k ≤ p < Fm−1, Fm+k < Fm+Fm−1 = Fm+1. So Fm+k is trapped strictly between two consecutive Fibonacci numbers — it cannot itself be one. Contradiction. LFib is not regular. ∎

Fm + k is trapped strictly between two consecutive Fibonacci numbers.

Common errors & misconceptions
  • The pumping length p need not be a Fibonacci number.
  • We must choose m after receiving p, specifically so that Fm−1 > p.
  • Merely choosing Fm > p is not enough — we need k ≤ p < Fm−1 so the pumped length stays below Fm+1.
  • The first few Fibonacci numbers repeat (F1=F2=1). Choosing m ≥ 3 avoids this irrelevant duplication.
  • We pump upward with i=2. Pumping down (i=0) may accidentally land on another Fibonacci length and needs extra analysis.
Case E

Equal Numbers of ab and ba

Σ = {a,b,c}    Lab=ba = { w ∈ Σ* | #ab(w) = #ba(w) }, counting overlapping substring occurrences.

For example, aba has one ab and one ba, so it belongs to the language; abcab has two abs and zero bas, so it does not.

Restricting to a two-block language. For w = (abc)m(bac)n, we get #ab(w) = m and #ba(w) = n. So intersecting with the regular language R = (abc)*(bac)* gives:

K = Lab=ba ∩ R = { (abc)n(bac)n | n ≥ 0 }

If Lab=ba were regular, closure under intersection would force K to be regular too. So we prove directly, by pumping, that K is not regular:

  1. 1

    Assume K is regular; let p be its pumping length.

  2. 2

    Choose s = (abc)p(bac)p. Then s ∈ K and |s| = 6p ≥ p.

  3. 3

    Since |xy| ≤ p and the first region (abc)p has length 3p > p, the substring y lies entirely within the first region. Let |y| = k, 1 ≤ k ≤ p.

  4. 4

    Case 3∤k: pumping down gives |xz| = 6p−k. Since 6p is divisible by 3 but k is not, 6p−k isn't divisible by 3 either — yet every string in K has length 6n, divisible by 3. So xz ∉ K.

  5. 5

    Case 3|k (k=3r, r≥1): since (abc)p is periodic with period 3, removing 3r symbols preserves phase, giving xz = (abc)p−r(bac)p. Since r ≥ 1, p−r ≠ p, so xz ∉ K either way. Both cases contradict the lemma — K is not regular, so Lab=ba cannot be regular over {a,b,c}. ∎

Common errors & misconceptions
  • The pumping length p counts individual symbols, not complete abc-blocks.
  • From |xy| ≤ p we may conclude y lies inside the first (abc)p region — but not that y is itself a sequence of complete blocks.
  • The adversary chooses x, y, z — we cannot assume y begins at a block boundary.
  • Both possibilities, 3∤|y| and 3||y|, must be considered separately.
  • If 3∤|y|, the simplest contradiction comes from total length alone — no need to analyze symbol boundaries.
  • Proving K non-regular is not the final conclusion by itself — closure under intersection is what carries the result back to Lab=ba.
A contrast worth noticing

§16Why the Extra Symbol c Matters

Over the binary alphabet {a, b}, the difference #ab(w) − #ba(w) depends only on the first and last symbols of w:

#ab(w) − #ba(w) = 1 if w starts with a and ends with b; −1 if it starts with b and ends with a; 0 otherwise.

That means equality can be checked with a handful of states — the language is regular over {a, b}.

Over {a, b, c}, occurrences of c chop the word into many separate binary segments. Each segment can contribute −1, 0, or +1 to the running difference, and these contributions can accumulate without bound — exactly the kind of unbounded counting a DFA cannot do.

Conclusion. The very same counting condition is regular over a two-symbol alphabet, but becomes non-regular the moment a third symbol is introduced. The alphabet is not just decoration — it can change the answer entirely.

Closing the lecture

§18Summary

  • Intuition: finite states and sufficiently long inputs force cycles.
  • Theorem: every sufficiently long string in a regular language must be pumpable.
  • Proof strategy: choose a string that traps the pumpable part in a vulnerable region.
  • Rigor: the argument must work for every valid decomposition s = xyz, not just a convenient one.
  • Alternative: when direct pumping becomes awkward, closure properties may be cleaner.
